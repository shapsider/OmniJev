How to generate new results

Run in the project root directory; it will actually call the local model, not train weights:

.venv-embodied/bin/python scripts/benchmark_embodied.py \
  --providers baseline omnijev omni_direct omni_reasoning \
  --tasks transfer stack barrier --seeds 0 1 2 \
  --output results/embodied/my-run

Initially test only one seed --seeds 0.Direct visual experiment switch to --providers omnijev omni_direct --observation vision --control incremental --max-cycles 60; It must be separately summarized from skill experiments.
